I'm forking https://github.com/hylyh/bondage.js/tree/2.0 _(note that's the "2.0" branch, not the "main" branch)_ to fix some bugs and add a feature.  Here is a list of changes I've made:
- Updated versions of library dependencies.
- Fix a few bugs related to order-of-operations.  For example: ```!m && !n``` was not evaluating the same as ```(!m) && (!n)```.
- Fixed a bug where only one decimal place was accepted for a number.  For example, ```<<set $first = 3.1>>``` and ```<<set $second = 314 / 100>>``` worked, but ```<<set $third = 3.14>>``` did not.
- Fixed a bug related to indenting messing up nested option collections.  They weren't being recognized as options if extra indenting occurred, such as for "if" blocks.
- Added the ability to save and restore the position within a node.  This means adding a ```generator.getPosition()```, which gets the current position within the node (an object storing the position within the tree), and modifying ```runner.run(x)``` to pass in either the original node-name argument, or a new argument that is the result of a call to "getPosition()".  The former works as before (running from the start of the node).  The second brings the generator back to specified line in the node.  This allows saving and restoring a runner to the exact line.
